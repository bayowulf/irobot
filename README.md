A cooperative party game of literal logic and physical comedy for **3–8 players** — built
for one 9-year-old + two parents + two grandparents.

One player becomes a rigid, instruction-following **Robot**. Everyone else are
**Controllers** who may speak *only* the words printed on the Command Sheet. The Robot
never learns the Challenge; the Controllers may never explain it. Fluent English collides
with a machine that takes every word at face value — and the laughs are in the gap.

---

## 🚀 0. Quick Start (read this first)

1. Print `command-sheet.html` (page 1 is required; page 2 is optional) and
   `challenge-sheet.html`. Cut the Challenge slips apart.
2. Pick one player as the **Robot**. Show the Challenge to everyone **except** the Robot.
3. Start the timer — **90 seconds** (or **60** for a quick round). It starts on the first
   command and is never paused or extended.
4. The Controllers **take turns in order** — each calls one command from the Command Sheet,
   then passes to the next Controller. The Robot does it, says **"COMPLETE,"** and waits for
   the next command.
5. Get the Challenge done before the timer hits zero. Call **"STOP"** the moment you think
   it's done.
6. Swap who plays the Robot and keep a shared tally of completed Challenges (§9).

---

## 🎭 1. Premise & Roles

- **The Robot (1 player):** Executes commands literally and mechanically. No common sense,
  no intuition, no guessing — and **no knowledge of the Challenge**. The Robot may not ask
  questions or be told the goal. This is the fun job and needs no reading: the best seat for
  the youngest or oldest player.
- **The Controllers (everyone else):** They can see the Challenge, and they run the timer.
  They may speak **only words printed on the Command Sheet**, plus **RUN**, **COMPLETE**,
  **STOP**, and **CHECK** (§6). They may not explain, hint, or coach in ordinary English.

> **The Robot is not a saboteur.** The Robot wants the team to win; it simply cannot use the
> goal to interpret commands. Misreads come from honest, literal reading — never from
> deliberately failing or secretly helping (§5).

## ⚙️ 3. Setup (each round)

1. **Pick the Robot.** Show the Command Sheet to everyone. The Robot keeps it in view too.
2. **Draw a Challenge.** One Controller draws a slip and reads it silently. Keep it hidden
   and unspoken around the Robot. (Slips are tagged Easy / Medium / Hard; pick a difficulty
   to suit the table, or draw at random.)
3. **Seat the Controllers** in a fixed calling order (1 → 2 → 3 → …) — see Passing the Mic,
   §6.
4. **Mark the start.** Tape the Robot's starting spot and note their starting posture
   (usually seated).
5. **Set the timer.** 90s standard, 60s quick. Agree before the first command.
6. **Begin.** The first Controller speaks the first command and the timer starts.

---

## 🔁 4. Round Flow

1. **First command** is spoken from the Command Sheet. The timer starts.
2. **Execute and beep.** The Robot performs that one command, then says **"COMPLETE."**
   No other words from the Robot.
3. **Next command.** Controllers feed commands one at a time, waiting for COMPLETE each time.
   They may repeat or rephrase using only sheet words (e.g. add a Parameter or a Target).
4. **Judging done.** When the group believes the Challenge is met, anyone calls **"STOP."**
   If it *is* met, the Challenge is a **success** — regardless of how silly the route was.
5. **Timer runs out.** If time expires first, the Challenge is a miss. Nothing is added or
   subtracted from the clock, ever.
6. **Score and rotate** (§9), then choose the next Robot.

### The timer
- **Standard 90s / Quick 60s**, chosen up front, started once, run to zero.
- A **"static"** (an illegal word — §6) costs a **5-second freeze** while the clock keeps
  running. Anyone at the table may call it out.

---

## 🌀 5. The Ambiguity Rule (the heart of the game)

Commands are intentionally underspecified. *TURN LEFT* — turn your head? your body? 45°?
90°? The Robot decides.

- **The Robot does not know the Challenge** and **may not ask for clarification.** It cannot
  be told what the Controllers are trying to achieve.
- When a command could mean more than one thing, the Robot **picks the reading that makes
  sense to it, announces it once** (e.g. *"INTERPRETATION: TURN LEFT means turn my whole
  body 90° left"*), and **stays consistent for the rest of the round.**
- **Fallbacks.** If the Robot would rather not invent a meaning, use the printed **Default
  Robot Behaviors** table (Command Sheet page 2, and §7 below). The Robot may also adopt a
  default and still announce it.
- **Good faith only.** The Robot may not choose a reading in order to fail, and may not
  quietly use the goal to succeed. If the table thinks a reading is in bad faith, the Robot
  picks again.
- **No gotchas.** This is not Simon Says. Nobody is trying to trick the Robot; the comedy
  comes from honest literalism meeting fluent, meaning-packed speech.

> **Why announce the interpretation?** It makes the game checkable, keeps everyone honest,
> and turns each choice into a shared joke the table can see coming.

---

## 🗣️ 6. How to Call Commands

- Speak **only words printed on the Command Sheet**, plus exactly these four referee words:
  **RUN · COMPLETE · STOP · CHECK**.
- **One command at a time**, then wait for the Robot's **COMPLETE**.
- **RUN** starts the round. **STOP** ends it. **CHECK** pauses *speech only* (not the clock)
  so anyone can confirm a rule or a reading, then play resumes.
- **Bracketed placeholders** on the sheet are filled from the TARGETS group or from the room
  as named on the sheet — e.g. `PICK UP` + `THE BALL`.
- **Illegal words = static.** Any word not on the sheet (other than the four referee words)
  is a **static**: the Robot freezes **5 seconds** while the timer runs. Then repeat a legal
  command and continue.

### Passing the Mic (hot-seat order)

With three or more Controllers, calling **rotates** so everybody plays every step of the way:

- Before the round, put the Controllers in a fixed order: **1 → 2 → 3 → 4**.
- Controller 1 gives command 1; when the Robot says **COMPLETE**, the turn passes to
  Controller 2 for command 2, then 3, then 4, then back to 1.
- The Robot still executes exactly **one command per turn**, and its announced
  interpretations stay fixed for the whole round even as the speaker changes.
- **Only the Controller whose turn it is** may speak a command; anyone may call **CHECK** or
  **STOP** on their own turn.
- If a Controller has nothing ready, they stay **silent** — a silent pass costs nothing — and
  the turn moves on.

## 🤖 7. Default Robot Behaviors

The full table is printed on Command Sheet page 2. Summary:

| Situation | Default |
| --- | --- |
| TURN LEFT / RIGHT, no degrees | Quarter turn (90°), whole body. |
| TURN HEAD LEFT / RIGHT | Head only, 90°; body still. |
| LOOK UP / DOWN | Eyes only; head still. |
| GO FORWARD / BACKWARD, no distance | One step. |
| No named hand | The **active hand** (right, unless the last command used the left). |
| GRASP, no target | Close the active hand on empty air. |
| PICK UP, no target | Grasp the object in front, lift 6 inches. |
| PUT DOWN, no target | Lower what you hold to the nearest surface, release. |
| SAY, no word | Say "beep." |
| WAIT, no seconds | Wait 3 seconds. |
| NOD / SHAKE HEAD | One motion. |
| STOP | Stop; stay stopped until a later command moves you. |
| FREEZE | Hold your exact pose until the next command. |
| RESET | Return to the starting spot, facing, and posture. |
| Any missing target | The object in front, if any; otherwise empty air. |

## 🎯 8. Challenges

Challenges describe an **outcome**, never a script — any legal route that gets there counts.
Difficulty is a suggestion; scale it to the table. Keep every slip hidden from the Robot.

The deck (`challenge-sheet.html`) has three difficulty bands plus an Advanced band:

- **Easy** — one or two commands' worth of action (pick up the ball and box it; wave; nod
  and shake).
- **Medium** — a short sequence, often with movement or a handoff (walk to the table and put
  the ball on it; walk to the door and open it).
- **Hard** — multi-step errands, wardrobe, and delivery loops (put on the jacket *and zip
  it up*; hand the cup to every human, one at a time; retrieve the glass and return to start).
- **Advanced** (tagged on the slip) — uses the optional page-2 commands: `WHILE`, `IF / THEN`,
  `REPEAT`, and sensors (hear a sound, touch sensor, distance, no obstacle).

> If a Challenge names a prop you don't have, skip that slip or substitute a similar object.

## 🧮 9. Scoring (cooperative)

iRobot is a **team-vs-the-clock** game: the table works together and tracks a shared tally.
Two scoreboards: the **shared Mission tally** and **personal points** (which last all night).

### Shared Mission tally
| Event | Mark |
| --- | --- |
| Complete a Challenge before time runs out | **+1 Mission** (note the difficulty) |
| Complete a **Hard** Challenge | **+1 bonus Mission** |
| Finish with **half the timer or more** remaining | **Speed Star** ⭐ |

### Personal points — per night (never reset)
| Event | Points | Who |
| --- | --- | --- |
| **Good Robot** — a Challenge completes on your turn as Robot | **+1** | The Robot |
| **Comedy Point** — funniest misread or moment (group vote, 1 per round) | **+1** | Any player |
| **Clean Run** — complete a Challenge without ever announcing an interpretation | **+1** | The Robot |

- Personal points let a shy player chase laughs or a careful reader chase Clean Runs.
- Misreads are never punished — they are the entertainment.

---

## 🏆 10. Winning the Night

Play until everyone has been the Robot at least once (or until you're done). There is no
loser — the table sets a shared goal before the night, then tries to beat it:

- **Good night:** one Mission.
- **Great night:** a Mission per player.
- **Legendary:** beat the "great" target *and* earn at least one Speed Star.

Then crown the personal titles:

- 🥇 **Robot MVP** — most Good Robot points.
- 😂 **Comedy Champion** — most Comedy Points.
- 🧼 **Clean Runner** — most Clean Runs.

Ties are broken by Comedy Points; if still tied, share the title.

---

## 🦺 11. Safety Override (absolute)

The Robot may refuse **any** command by saying **"WILL CAUSE INJURY."**

- It costs nothing. No penalty, no argument, no vote.
- The Controllers must replace that command and continue.
- **Safety questions are never scored.** If in doubt, refuse.
- **If a Robot ever loses track of the challenge or feels pressured to act unsafely, the
  Safety Override wins — always.**

To keep everyone in the game, the base commands avoid kneeling, crawling, and fast spinning
for at-risk players. Use Seated Mode for a gentler round.

---

## 🪑 12. Seated Mode (gentle play)

For a grandparent, an injured player, or a tired kid.

- The Robot stays **seated** for the whole round. Skip any command that requires standing,
  kneeling, lying down, or walking, and substitute its seated nearest-equivalent (arm, hand,
  head, and voice commands only).
- Seated Mode adds **30 seconds** to the timer (standard 120s, quick 90s). Limits are chosen
  up front and never extended mid-round.

---

## 🧩 13. Advanced Commands (optional)

Page 2 of the Command Sheet adds a small programming layer for tables that want it:

- **`REPEAT [N] TIMES`** — say the block once; the Robot performs it N times.
- **`IF / THEN`** — immediately followed by a sensor; the block runs only if the sensor is
  true.
- **`WHILE`** — immediately followed by a sensor; the block repeats while it stays true.
- **Sensors:** `TOUCH SENSOR = PRESSED` · `HEAR SOUND = YES` · `DISTANCE < 6 INCHES` ·
  `NO OBSTACLE`.

Example: **REPEAT 3 TIMES — RAISE RIGHT ARM — LOWER RIGHT ARM.**

Leave page 2 unprinted for the simplest game. The Advanced Challenges are tagged on the slips.

## 📋 14. Cheat Sheet

**Roles:** 1 Robot (literal, blind to the Challenge, cannot ask) · Controllers (see the
Challenge, speak only sheet words + RUN/COMPLETE/STOP/CHECK).

**Loop:** one command → Robot executes → **COMPLETE** → next command → call **STOP** when done.

**Calling order:** Controllers take turns (1→2→3→4→1); one command each, then pass. Silent
pass is free.

**Timer:** 90s standard / 60s quick (Seated +30s). Starts on the first command, runs to zero,
never extended.

**Ambiguity:** Robot picks a reading, **announces it once**, keeps it all round, in good
faith. Fall back to Default Robot Behaviors if preferred.

**Static:** any word not on the sheet = **5-second freeze**, clock still running.

**Scoring:** +1 Mission per Challenge, +1 bonus for Hard · Speed Star for finishing with
≥ half the clock left · personal: Good Robot, Comedy Point, Clean Run.

**Titles:** Robot MVP · Comedy Champion · Clean Runner.

**Safety:** "WILL CAUSE INJURY" is always valid, always free. Then replace the command.

**Modes:** Standard 90s · Quick 60s · Seated (+30s, seated commands only) · Advanced (page 2).
