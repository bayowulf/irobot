iRobot · REFERENCE

Fallback meanings & the optional Advanced layer.
Print only if you want them.
The ambiguity rule. The Robot does not know the Challenge and may not ask for clarification. When a command has more than one reading, the Robot picks the reading that makes sense, announces it once, and keeps it for the round. Use this table as the fallback if the Robot would rather not invent one. Acting in bad faith to fail or to secretly help is not allowed.

Advanced Commands (optional — use with the Advanced Challenges)

REPEAT [N] TIMES IF / THEN ELSE WHILE TOUCH SENSOR = PRESSED HEAR SOUND = YES DISTANCE < 6 INCHES NO OBSTACLE

A sensor is said right after IF / THEN or WHILE, then the block is spoken once and repeated the stated number of times. Example: REPEAT 3 TIMES — RAISE RIGHT ARM — LOWER RIGHT ARM.
